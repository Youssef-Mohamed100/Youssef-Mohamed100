File Path Traversal

Traversal (directory) vulnerabilities let an attacker read or write arbitrary files on the application server — application code, data, credentials, and OS files — potentially leading to full system compromise. These flaws are dangerous because stolen credentials or modified files let attackers escalate privileges, maintain access, and move laterally within the network.
